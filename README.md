# روقان (RWAKAN) — صفحة التحميل + ملفات المشروع

مجلد واحد فيه كل حاجة تخص موقع تعريف تطبيق «روقان»:

| الملف / المجلد | إيه هو |
| --- | --- |
| `index.html`, `style.css`, `app.js` | كود صفحة الهبوط العربية (RTL): المزايا، الخزنة، الخصوصية، الأسئلة، وزرار التحميل. |
| `screens/` | ٦ لقطات حقيقية من التطبيق من داخل هاتف أندرويد 16، تظهر في الشريط المتحرك وفوق قسم «من جوه روقان». |
| `RWAKAN.apk` | نسخة النشر الموقّعة 1.1.0 (6.4 ميجابايت) — نفس الملف اللي بيتنزّل من الموقع. |
| `serve.mjs` | سيرفر صغير يشغّل الصفحة على جهازك: `node serve.mjs` ثم تفتح الرابط اللي بيظهر. |
| `README-تطبيق-روقان.md` | شرح التطبيق نفسه (المزايا، طريقة البناء، الاختبارات). |

## مفيش هنا (ومفروض ميكونش)

- `rwakan-release.keystore` — مفتاح توقيع التطبيق.
- `keystore.properties` — كلمات المرور.

دول **أسرار**؛ رفعهم على أي موقع = أي حد يقدر ينشر تحديثات باسمك.
احفظهم لوحدك في نسختين خارج المشروع (سحابة خاصة أو فلاشة)، ومفيش بديل لو ضاعوا.
